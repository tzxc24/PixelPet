# PixelPet V1.2 RC4

发布日期为 2026 年 11 月 26 日。

## 本次更新

- ESP32 语音请求需要以小星或支持的同音称呼开头。未匹配请求在转写后跳过。环境语音仍会上传进行识别。
- 支持北京时间报时和语音提醒，扩展报时问法。
- 说“小星小星，五分钟之后叫我”设置单次音乐闹钟。起床旋律使用 assets/music/02_wakeup_loop.wav，循环或裁剪至十秒。
- 三首音乐支持即时播放和定时。网页新增灯光和定时音乐操作区。
- GPIO 3 输出高有效的 3.3V、1kHz PWM，灯板 PWM 接 GPIO 3，GND 共地，灯板另行供电。支持亮度、渐亮、渐灭和呼吸模式。灯板须支持该输入规格。
- 明确的语音时间命令支持音乐与三十秒渐亮联动。
- 支持能力协商后的长回复分段音频，旧固件继续整段播放。
- 默认自动健康回访。模型根据本轮用户自述输出主题和摘要，服务器按主题去重，默认三天后在下次普通聊天时询问。可说“小星，取消健康回访”或“小星，关闭健康回访”。

## 升级与构建

先更新服务器源码和 assets/music，再更新 ESP32 固件。沿用原有密钥、联网参数和数据库。保持服务账号对数据库目录的写入权限。

在已安装项目指定 ESP-IDF 和 ESP-SR 依赖的环境中，使用 firmware/pixelpet_s3/sdkconfig.continuous.defaults 作为配置，按 docs/firmware_build.md 编译。

发布附件为 ESP32-S3 应用镜像。刷写前确认板卡接线与本项目相符，并确认 factory 分区从 0x10000 开始且容量足够。镜像写入 0x10000。固件内部标识沿用已实测的 1.3.0-dev.3。

网页访问根路径，语音和灯光设置在同一服务内生效。远程访问需要部署时设置的 PixelPet 访问令牌。

## 实测与限制

十秒音乐闹钟已多次通过实物播放测试，记录到约 10.06 秒并收到完成回执。历史测试存在偶发重连或播放中断，原因尚未完全确定。灯板实际亮度效果仍待确认。

定时为单次。设备在线并空闲时执行，离线超过十分钟的音乐定时跳过。播放期间暂停收音。固定时长闹钟使用本地缓冲连续播放，网页停止不能中途打断这十秒。

健康回访按粗粒度主题去重，同一主题更新摘要。回访在生成回复时消耗，播放中断后不会自动补问。真实三天到期的语音回访尚待验证。分类摘要可能出现偏差。

自动健康回访仅在普通模型问答中提取，报时和设备控制等本地指令直接处理。用户说已经好转时不会创建新摘要，现有待回访任务可用取消口令清除。

本仓库包含程序及指定铃声。凭据、联网配置、聊天数据库、健康摘要与录音保存在部署端。

本次发布运行 280 项 Python 测试、11 项 C++ 主机测试，全部通过。ESP32-S3 连续监听配置编译通过。固件镜像大小为 977088 字节。
