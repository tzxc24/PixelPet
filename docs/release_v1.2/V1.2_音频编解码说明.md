# 音频编解码

PixelPet 二进制音频帧使用 PCM16LE 单声道，上行 16 kHz，下行 24 kHz。播放前校验 metadata 中采样率、声道、format、byte_count，按 UUID 和序号拼接。WAV 由服务器封装输入供 Whisper 使用。PyAV 解码 Edge 源音频并进行 24 kHz 转换。

小智独立适配以 libopus 实现原始 Opus 包。上行测试 16 kHz，下行测试 24 kHz，样本使用 60 ms 帧，包含对异常包和状态的验证。普通 PCM 端点不接收 Opus。

复验：`.\.venv\Scripts\python.exe -m pytest tests/test_virtual_voice.py tests/test_xiaozhi_opus.py tests/test_voice_cache.py -q`。硬件端数据有效位、I2S 时序、响度和实测吞吐均为 HW_PENDING。
