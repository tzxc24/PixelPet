# 故障排查与启动

双击项目根目录 start_pixelpet.bat。启动器检查 Python 和依赖，识别端口占用。相同版本提示复用，旧版本退出码 4，其他占用退出码 2。退出旧实例后重新启动，终端按 Ctrl+C 正常停止。旧服务仍在运行时，首页静态内容可能已更新，应以 /api/status 的版本为准。

启动预检读取配置和 SQLite，确认前端入口，并显示 AI 提供方或 Mock。检查 .env 是否配置正确，禁止把模型密钥放到客户端。默认绑定 127.0.0.1。局域网联调需显式绑定 PC 私网地址，设置 PIXELPET_ALLOWED_HOSTS 及独立 PIXELPET_ACCESS_TOKEN，并限制防火墙来源。可参考 docs/deployment_windows.md。

诊断入口 /device-debug。先确认音频设备与语音服务就绪。识别失败时核对输入 PCM、长度和权限。TTS 失败保留文字，可重试。断网后等待设备重连，使用新录音会话。数据库无法打开时检查权限、磁盘和锁定状态，按备份说明恢复到新路径。启动器的错误日志位于 output/logs/service-errors.log，仅记录失败阶段与状态码。
