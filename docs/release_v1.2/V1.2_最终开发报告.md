# PixelPet V1.2-RC2 最终开发报告

本轮基于 V1.1 源码和 RC1 归档。新增了安全的 SQLite 备份检查与恢复、录音会话期限、设备端 ASR 开关保护及启动预检。版本为 1.2.0-rc.2，启动器识别并拒绝静默复用旧版本。默认晓伊和现有 DeepSeek 配置沿用。私有数据库未用于自动化语音验证。

真实 VirtualESP32 PCM 链路已复验。小智 Opus 模块和 PCM 路由分别验证。小智原生网络接入为 BLOCKED。固件增加串口与 PSRAM、独立 Wi-Fi 和 ST7789 局部动画测试模式，并调整显示 DMA 缓冲生命周期与超时。原有硬件门控保留。端侧实时状态绘制、RMS 嘴型和震动整机联动仍为 BLOCKED。PSRAM 实际容量、显示刷新、收放音、物理 Wi-Fi 和外设均为 HW_PENDING。

本轮代码变更集中在 `scripts/start.ps1`、`scripts/run_server.py`、`scripts/backup.py`、`scripts/archive_release.py`、`scripts/verify_v11_device_live.py`、`backend/release.py`、`backend/api/devices.py`、相关 Python 回归测试和固件的 `build.ps1`、`Kconfig.projbuild`、`hardware_smoke`、`drivers.cpp`、`main.cpp`、`network`。文档与依赖清单随发布归档。

本机工作目录没有 Git 元数据，使用源码 ZIP 做 RC2 备份，保留此前 RC1 归档。新版压缩包及 SHA-256 位于 output/v1.2。配置密钥按完整值比较，范围为白名单源码和限长文本报告与日志。历史对话曾出现 DeepSeek 密钥，需由用户在服务商端撤销或更换。

回到工位先核对板卡和模块丝印、排针与电源资料，随后空板 USB 串口测试。实体联调按硬件到货手册逐项进行。
