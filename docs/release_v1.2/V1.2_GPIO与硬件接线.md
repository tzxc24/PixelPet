# GPIO 与硬件接线

唯一配置源是 `hardware/pinmap.json`。使用 `python scripts/generate_pinmap.py --check` 核对固件头文件。下表是计划信号，全为 HW_PENDING。实际排针以具体开发板的丝印、原理图和断电通断测量为准。

| 模块 | 信号与 GPIO | 现场需确认 |
|---|---|---|
| ST7789 | SCK 14，MOSI 15，RST 16，DC 17，CS 18 | VCC、逻辑电压、RGB/BGR、偏移和 SPI |
| ST7789 BL / CS-F | 均禁用，GPIO10 仅预留 BL | BL 限流及驱动结构、CS-F 有效极性及空闲非选中电平 |
| INMP441 | BCLK 4，WS 5，SD 6 | 模块供电规格、L/R 槽选择、有效位和地 |
| MAX98357A | BCLK 7，LRC 8，DIN 9 | 供电电压、电流预算、SD/MODE 和扬声器额定值。扬声器跨接 SPK+ 与 SPK−，两端均与地隔离 |
| TTP223 | OUT 13 | 模块供电、3.3 V GPIO 兼容、高有效暂定、瞬时/锁存跳线 |
| MOS 马达板 | IN 21 | 马达额定电压与电流、3.3 V 输入阈值、默认关断、续流保护和供电 |

计划分配避开启动 GPIO0/3/45/46、USB GPIO19/20 及预留给 Flash/PSRAM 的 GPIO26–37。禁止通过 GPIO 给马达供电。断电核对地线、连接与短路。电源、电平、背光和马达条件未确认时保持所有硬件门控关闭。[Espressif GPIO 指南](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/gpio.html)
