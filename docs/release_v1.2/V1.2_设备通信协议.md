# 设备通信协议

旧控制端点和 PCM 语音端点分离。语音路径为 `/api/devices/voice/ws?device_id=...`，LAN 使用配置的 Bearer 令牌和 Host/Origin 检查。

客户端 hello 后用 record.start 获取 UUID，可传 conversation_id 恢复上下文。二进制帧以 16 字节 UUID 和大端 uint32 音频序号开头，序号每方向从零计数。record.stop、cancel 带当前 UUID。下行包含 thinking、playback.start、PCM 帧、playback.end，后续轮次用返回的 conversation_id。控制帧以连接内状态和 UUID 校验，PCM 语音端点未定义独立控制序号。旧 JSON 控制端点仍有序号规则。

帧长最多 4096 字节 PCM。录音最多 20 秒数据，25 秒墙钟收包上限，90 秒语音任务上限。超时或取消清理状态，迟到会话帧和重复音频序号被拒绝。重连重新握手，不继续未完成音频。Whisper 停用时拒绝开始设备录音，处理前也复核设置。

小智使用独立的 hello、session_id、listen、stt、llm、tts、abort 和原生 Opus 封包。当前适配模块有独立编解码与协议状态测试。没有公开原生端点或实机互通记录。 [上游协议](https://github.com/78/xiaozhi-esp32/blob/main/docs/websocket.md)
