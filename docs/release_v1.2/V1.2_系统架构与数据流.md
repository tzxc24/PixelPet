# 系统架构与数据流

PC 页面经 HTTP 上传 WAV 或浏览器录音，识别调用本地 Whisper。VirtualESP32 和 ESP-IDF 则经独立 PCM WebSocket 上传样本，服务端先封装 WAV，再复用同一识别器。聊天服务读取当前会话历史并检索 SQLite 长期记忆，使用可配置的 DeepSeek Chat Completions，保存回复后交由 Edge 合成。设备端回传 24 kHz PCM，PC 浏览器接收 WAV 并用 RMS 驱动嘴型。

DeepSeek 参数对照当前官方文档核实。代码设置模型、messages、stream、max_tokens、JSON response_format，SDK 用 extra_body 传递 thinking。SDK 禁止隐式重试。取消可终止本地等待，已到达云端的请求可能仍计费。当前会话历史按会话 ID 查询，长期记忆是本机实例共享的资料，属于单用户部署边界。需要不同用户隔离时使用独立实例与数据库。模型密钥留在服务端。 [官方接口](https://api-docs.deepseek.com/api/create-chat-completion/) · [官方思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)

Edge 使用所选音色，晓伊为默认。实时浏览器语音支持结束、取消、队列边界和语音诊断。设备故障返回结构化错误，不切换成 SAPI。
