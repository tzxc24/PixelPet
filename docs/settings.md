# 设置、提醒与本地数据

设置通过 `GET/PATCH /api/pet/settings` 读写，保存在现有 SQLite `pet_settings` 的 owner 名下。重启保留。界面无需接触 API 密钥；密钥仍由本地环境配置。支持昵称、音量、语速、声音、麦克风、亮度、振动、安静时段、IANA 时区、12/24 小时制、主动关怀开关与每日通知上限，以及识别/合成来源、模型和性格。音量范围 0–1，语速 0.5–2，亮度 0.1–1，振动强度 0–1。

默认时区为 Asia/Shanghai，安静时段 22:00–08:00，主动关怀关闭，每日最多 3 条提醒。安静时段跨午夜时正常生效；开始与结束相同时表示不启用安静时段。Windows 需要安装 tzdata。

## 提醒

`POST /api/reminders` 接收 `{"text":"喝水","due_at":"2026-11-05T10:00:00+08:00"}`。时间必须带时区；保存时统一为 UTC。`GET /api/reminders` 查看，`DELETE /api/reminders/{id}` 删除。最多保存 1000 条，已送达记录可以手动删除。

`GET /api/notifications/poll` 原子领取已到期提醒。显式创建的提醒不依赖主动关怀开关；主动关怀默认关闭；开启后，在本地09/14/19点起的当前时段各至多一次固定问候，持久去重、不追补往期时段，不调用付费模型。它与显式提醒共享每日上限，提醒优先。安静时段和每日上限会延后提醒；超过原到期时间 24 小时则标为 expired，不再补发。上限为 0 时不送达；每日按设置时区的日期计数，重启保留。

只有应用运行且客户端持续轮询时才能通知。关闭应用或电脑不会后台通知；再次打开后按上述延后/过期规则处理。送达标记先提交，再返回客户端，避免重启或多客户端重复送达；若提交后客户端断开，提醒可能未显示，不保证重试。

## 记忆与备份

`GET /api/memories/export` 下载 JSON，内容仅为主人资料与记忆，不包含配置密钥。`DELETE /api/memories` 事务清空 owner 的所有长期记忆并重置主人资料；保留聊天记录、宠物设置和提醒。聊天回复进行中返回 409，结束后再操作。

执行 `.venv\Scripts\python.exe scripts\backup.py` 使用 SQLite 在线备份接口，备份实际配置的数据库到 `output/backups`，不会复制 `.env`。可用 `--destination D:\PixelPet\output\backups\my-backup.sqlite3` 指定文件，路径必须位于该目录内，已有文件不会覆盖。备份包含聊天与记忆等本地数据，请自行妥善保管。
